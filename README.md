# Ludo Income - Render Ready

This package fixes the Render build error caused by a missing `package.json`.

## Render settings
- Environment: Node
- Root Directory: leave empty (repository root)
- Build Command: `npm install`
- Start Command: `npm start`
- Node: 18+

The public UI is `/` and the demo admin UI is `/admin`.

This package is a frontend/demo deployment shell. It does not implement real-money transactions, wallet settlement, or production authentication.
